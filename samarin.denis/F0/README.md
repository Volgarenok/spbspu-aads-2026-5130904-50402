# F0 — Перекрёстные ссылки. Индексация текста

Текст загружается и сразу превращается в инвертированный индекс (слово —
список позиций), оригинал отбрасывается. Все остальные команды работают с
индексом: он восстанавливается в сетку строк и слов, преобразуется и
индексируется заново. Перекрёстные ссылки выдаются прямо из индекса.

## Как это устроено

- Документ хранится как индекс `слово → список позиций (строка, слово)` плюс
  список длин строк (чтобы восстановить пустые строки и число строк).
- `show`/`save` восстанавливают текст из индекса; пробелы между словами
  нормализуются до одинарных, пустые строки сохраняются.
- Редактирование и структурные операции работают по схеме
  «восстановить → изменить → переиндексировать».

## Структуры данных

- `List` (S1) — односвязный список, лежит в `common`.
- `Stack`, `Queue` (S2) — построены поверх `List`.
- `CuckooTable` (S3) — хэш-таблица на кукушкином хэшировании с двумя хэш-
  функциями; хранит инвертированный индекс, коллекцию документов и таблицу
  команд.

## Общие правила

- Команды читаются из стандартного ввода, по одной в строке.
- Номера строк и слов начинаются с единицы.
- Некорректная команда (нет документа, занятый id, индекс вне диапазона,
  неизвестная команда или флаг, не открылся файл) печатает `<INVALID COMMAND>`
  и обработка продолжается.
- `list`, `find`, `dump-index` на пустом результате печатают `<EMPTY>`.
- Код возврата: `0` — нормальное завершение (по `exit` или концу ввода),
  `2` — фатальная ошибка.

Примеры ниже используют файл `poem.txt`:

```
the cat and the dog
the dog ran fast
cats and dogs play
```

## Базовые команды

### `load <file> <id>`
Читает файл `<file>`, строит по нему индекс и сохраняет под именем `<id>`.
Оригинальный текст отбрасывается. Ошибка, если `<id>` уже занят или файл не
открылся.

```
> load poem.txt p
```

### `save <id> <file>`
Восстанавливает текст документа `<id>` из индекса и пишет его в `<file>`.
Ошибка, если документа нет или файл не открыть для записи.

```
> save p out.txt
```

### `show <id>`
Печатает восстановленный текст документа.

```
> show p
the cat and the dog
the dog ran fast
cats and dogs play
```

### `list`
Печатает идентификаторы всех документов по алфавиту, по одному в строке;
`<EMPTY>`, если документов нет.

```
> list
p
```

### `drop <id>`
Удаляет документ. Ошибка, если документа нет.

```
> drop p
```

### `help`
Печатает список доступных команд.

### `exit`
Завершает работу (чтение команд прекращается).

## Редактирование

Все индексы — с единицы.

### `replace <id> <line> <word> <new>`
Заменяет слово в позиции `(line, word)` на `<new>`.

```
> replace p 1 2 lion
> show p
the lion and the dog
the dog ran fast
cats and dogs play
```

### `swap <id> <line1> <word1> <line2> <word2>`
Меняет местами два слова.

```
> swap p 2 2 3 1
> show p
the cat and the dog
the cats ran fast
dog and dogs play
```

### `insert-line <id> <pos> <words...>`
Вставляет новую строку из `<words...>` перед позицией `<pos>`. Если `<pos>`
равно «число строк + 1» — строка добавляется в конец. Без слов вставляется
пустая строка.

```
> insert-line p 1 brand new line
> show p
brand new line
the cat and the dog
the dog ran fast
cats and dogs play
```

### `remove-line <id> <pos>`
Удаляет строку `<pos>`.

```
> remove-line p 2
```

## Структурные операции

Каждая создаёт новый документ `<new_id>` (он должен быть свободен).

### `concat <id1> <id2> <new_id>`
Строки первого документа, затем строки второго (последовательно).

### `concat-lines <id1> <id2> <new_id>`
Построчная склейка: строка i — слова `id1[i]`, затем слова `id2[i]`. Если
длины разные, лишние строки берутся как есть.

```
# для "a b / c d" даёт "a b a b / c d c d"
> concat-lines g g q
```

### `repeat-vertical <id> <k> <new_id>`
Повторяет весь текст `k` раз сверху вниз.

### `repeat-horizontal <id> <k> <new_id>`
В каждой строке повторяет её слова `k` раз по горизонтали.

```
# "a b" -> "a b a b a b"
> repeat-horizontal g 3 r
```

### `interleave-lines <id1> <id2> <new_id>`
Чередует строки двух текстов (строка из первого, строка из второго, ...);
остаток более длинного дописывается в конец.

### `interleave-words <id1> <id2> <new_id>`
В каждой строке чередует слова двух текстов.

```
# "a b" -> "a a b b"
> interleave-words g g r
```

### `reverse-lines <id> <new_id>`
Обратный порядок строк.

### `reverse-words <id> <new_id>`
В каждой строке обратный порядок слов.

### `transpose <id> <new_id>`
Меняет строки и столбцы местами (для «рваных» строк недостающие ячейки
пропускаются).

```
# "a b c / d e" -> "a d / b e / c"
> transpose g t
```

## Поиск

### `find <id> <word> [--limit=k] [--from=start|end] [--edge=left|right] [--context=k]`
Ищет все вхождения `<word>`. Для каждого печатает `строка слово:` и окно
контекста, выделяя искомое слово в `[...]`. Флаги можно комбинировать в любом
порядке:

- `--from=start|end` — перебор с начала (по умолчанию) или с конца текста;
- `--limit=k` — вывести не более `k` вхождений;
- `--context=k` — показать по `k` слов контекста (по умолчанию `0`);
- `--edge=left|right` — показывать контекст только слева или только справа
  (по умолчанию — с обеих сторон).

`--from`/`--limit` задают, какие и сколько вхождений взять; `--context`/`--edge`
задают, как показать каждое. Если слова нет — `<EMPTY>`.

```
> find p the
1 1: [the]
1 4: [the]
2 1: [the]

> find p the --context=1
1 1: [the] cat
1 4: and [the] dog
2 1: [the] dog

> find p the --from=end --limit=1
2 1: [the]
```

### `find-first <id> <word> <k>`
Первые `k` вхождений (то же, что `--from=start --limit=k`).

### `find-last <id> <word> <k>`
Последние `k` вхождений (то же, что `--from=end --limit=k`).

### `find-around <id> <word> <k>`
Все вхождения с `k` словами контекста с обеих сторон (то же, что `--context=k`).

```
> find-around p dog 1
1 5: the [dog]
2 2: the [dog] ran
```

### `find-count <id> <word>`
Число вхождений слова (`0`, если слова нет).

```
> find-count p the
3
```

`find-first`, `find-last`, `find-around`, `find-count` — узкие варианты `find`
под один сценарий; сам `find` остаётся общим комбинируемым вариантом.

## Отладка

### `dump-index <id>`
Печатает индекс: слова по алфавиту, для каждого — отсортированные позиции
`(строка, слово)`. `<EMPTY>` для пустого документа.

```
> dump-index p
and: (1,3) (3,2)
cat: (1,2)
cats: (3,1)
dog: (1,5) (2,2)
dogs: (3,3)
fast: (2,4)
play: (3,4)
ran: (2,3)
the: (1,1) (1,4) (2,1)
```

## Пример сессии

Ввод:

```
load poem.txt p
dump-index p
find p the --context=1
replace p 1 2 lion
transpose p t
show t
find-count p the
save t out.txt
list
drop p
list
exit
```

Вывод:

```
and: (1,3) (3,2)
cat: (1,2)
cats: (3,1)
dog: (1,5) (2,2)
dogs: (3,3)
fast: (2,4)
play: (3,4)
ran: (2,3)
the: (1,1) (1,4) (2,1)
1 1: [the] cat
1 4: and [the] dog
2 1: [the] dog
the the cats
lion dog and
and ran dogs
the fast play
dog
3
p
t
t
```

Здесь `transpose` применился к уже отредактированному тексту (после `replace`
слово `cat` стало `lion`); `list` показал `p` и `t`, а после `drop p` остался
только `t`.
